# lexplataformae

Atlas, roteiro e laboratório do regime jurídico do Objeto Imaterial de Consumo (OIC) sob a Lex Plataformae. A partir da tese de doutorado de Victor L. P. Andrade (UNESP, 2026).

## Situação

No ar em https://lexplataformae.com.br, em português e em inglês, servido pelo GitHub Pages a partir da pasta `docs/`.
